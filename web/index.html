            מה מותר לשלוח לענן
            
        
            
        
              בענן עונה מודל של הספק, אבל המפתחות, הכלים והפעולות נשארים במק. מה שכבוי כאן לא נשלח בכלל, גם לא מתוך שיחה שהתחילה במק.
              "כשאני מבקש": המק עונה, ובמשימה מורכבת שואל אם לעבור לענן. "תמיד בענן": כל שיחה בענן, ואם הענן לא זמין עונה המק.
              בכל מצב אפשר לכתוב "תעבור לענן" או "תחזור למק", או ללחוץ על המתג ליד תיבת ההודעה.
            
        
          
        
          
        
            התראות
            
        בודק…
        
            
        
              
              
            
        
            
          
              
          • 
            
        
            
        
              התראה מגיעה כשתשובה מוכנה אחרי שיצאת מהאפליקציה, כשמשהו מחכה לאישור שלך, כשסוכן קוד סיים או נעצר, וכשהחיבור ל־Google צריך חידוש.
              המק מצפין כל התראה כך שרק המכשיר הזה יכול לפתוח אותה. Apple רק מעבירה אותה ולא יכולה לקרוא.
            
        
          
        
          
        
            גישה לקבצים במק
            
        
              בריין יכול לחפש, לקרוא ולשלוח קבצים מכל תיקיית הבית, חוץ ממקומות עם סודות (מפתחות, סיסמאות, נתוני דפדפנים).
              מחיקה היא רק העברה לסל, ורק אחרי שתאשר בכרטיס. אין לו כלי שעורך קבצים.
            
        
            
          
            
            
          
              אם תיקייה מסומנת ✗: בפעם הראשונה macOS מציג במק חלון "node רוצה גישה". צריך ללחוץ שם אישור. אם החלון לא הופיע:
              הגדרות המערכת ← פרטיות ואבטחה ← גישה מלאה לדיסק ← ＋ ← להוסיף את הקובץ
              
              ← ואז במק: npm run service:install
            
          
          
          
          
          
            מייל ויומן (Google)
            
          בודק…
          
            
            
            
            
              החיבור נעשה במק: בטרמינל, בתיקיית brain, להריץ npm run google:connect
              ולאשר בדפדפן. אותה פקודה מוסיפה חשבון נוסף (למשל עבודה). ההוראות המלאות ב־TESTING.md (שלב 5).
              ההרשאה נשמרת ב־Keychain של המק בלבד.
            
            
            
            בריין קורא מייל ויומן בלי לשאול. שליחת מייל וקביעת אירוע רק אחרי שתאשר בכרטיס.
            
          
            
          
            
            יומן, תזכורות, אנשי קשר, פתקים והודעות (Apple)
            
              
            
              
              החיבור נעשה פעם אחת במק: בטרמינל, בתיקיית brain, להריץ npm run apple:setup
              ולאשר כל חלון ש־macOS מציג. מה שמחובר במק מחובר גם לאייפון (דרך iCloud).
            
              
            
              יצירת אירוע, תזכורת, פתק או שליחת הודעה רק אחרי שתאשר בכרטיס.
